之前上班的时候，公司用的一个很老版本的mybatis。具体怎么写查询语句记不清了，大概是：

```java
User query = new User();
query.setStatus(1);
query.setUsername("张三");
List<User> list = userMapper.select(query);
```

我觉得太啰嗦，就写了一个工具类，可以做到类似如下调用。

```java
List<User> list = QueryBuilder.start(User.class)
.andEqual("status", 1)
.andEqual("username", "张三")
.query();
```

不过只有我自己用，同事们都不太愿意用，后来也就不了了之了。一开始只写了单表查询的，后来也补上了一个支持join查询的版本，不过没有合入公共分支，算是自娱自乐了。最近发现drizzle也是类似的写法，当然比我写的要更强大，比如支持自动补全、支持insert等。
